## What changed

### Per-class details

- **OutboxPublishServerDelivers** (2): The tests sign a `Block` request as alice and POST it to A's outbox
  (`/ap/v1/u/alice/outbox`); A's server (not the client) delivers the `Block` to bob's inbox on B, signed as
  alice. B validates the signature against alice's actor document (fetched from A) and records the
  alice→bob block edge. The fixture seeds alice + bob with keys ONCE; A's identity (for signing outbound
  deliveries) + `RoutingFetcher` (fetches A's and B's actor docs) + `DeliveryTransport` to B; B's fetcher
  reaches A (lazily, via `LazyHandler`). The second test seeds a fresh `carol` on B (a non-follower) and
  asserts the `Block` is NOT recorded for carol (single directed delivery, not broadcast).

### Notes

- The client (`_aHttp`) is created in the test class constructor from `fixture.ServerA.CreateHandler()`
  (not in `InitializeAsync`), since `ServerA` is available immediately after the fixture is constructed.
- The `SignedRequest` helper (which captures a signed request via a `CaptureHandler` and replays the signed
  headers onto a fresh request) is a private instance method (it uses `AHost` but no fixture state).
