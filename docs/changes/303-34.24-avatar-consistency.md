# 34.24 — Avatar consistency

**Phase 34 — UI polish & engagement**

## What was built

Avatars are now circular (`border-radius: 50%`) and consistent in size (64px / 4rem) across all pages that display them (profile, actor detail).

## Changes

### `apps/Iris.Web/wwwroot/css/app.css`

- `.actor-profile-avatar`: `border-radius: 0.5rem` → `border-radius: 50%`
- `.actor-profile-avatar-img`: `border-radius: 0.5rem` → `border-radius: 50%`

## Design decisions

- **Only CSS change needed.** The `ActorProfile` component is used on both the profile page and actor detail page, so a single CSS change covers both. The directory and object headers don't display avatars (they show text handles only), so no other changes were needed.
- **50% border-radius** is the standard circular avatar pattern.
- **Size unchanged (4rem / 64px).** The task asked for consistency, not a size change. Both pages already used the same size.
