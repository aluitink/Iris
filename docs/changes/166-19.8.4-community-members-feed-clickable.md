# 166 — Phase 19.8.4: community members + feed items clickable

## Summary

The `Community` page's **Members** card now renders each member as a clickable link to the member's
actor detail (the members collection is served as bare actor IRI links), and the **Feed** card wraps
each rendered item in a clickable object deep-link (`/object?iri=…`) so selecting a feed item navigates
to the full object detail. This closes the "members (clickable)" and "feed (rendered items, clickable)"
parts of 19.8.4.

## What changed (code)

- **`samples/SampleBlazorClient/Pages/Community.razor`**
  - **Members card**: each member item (an `ILink { Href }` bare actor IRI, or an `IObject { Id }`) is
    now a clickable `<a href="/actor?iri=…">` to the member's actor detail (the same shape + pattern as
    the followers/following cards). A non-link/non-object fallback still renders via `ObjectView`.
  - **Feed card**: each feed item is now wrapped in a clickable `<a href="/object?iri=…"
    class="object-feed-link">` around the `ObjectView`, so the whole rendered item is the click target
    navigating to the object detail page. The `FeedObjectIri(item)` helper resolves the item's IRI (the
    object id, or the link href) as the deep-link target; an item with no resolvable IRI renders without
    a link.
  - New `@code` helper: `FeedObjectIri(IObjectOrLink)` (the feed item's object IRI for the deep link).
- **`samples/SampleBlazorClient/wwwroot/css/app.css`** — `a.object-feed-link` (block-level, inherits
  color, hover highlight) so a feed item's whole rendered block is the clickable target.

## Key types / API

- `IActivityPubClient.GetCollectionItemsAsync(Iri, …)` — the members read (`{community}/members`,
  served as bare actor IRI links via `ActorIrisToLinks`).
- `IActivityPubClient.GetCommunityFeedAsync(Iri, …)` — the feed read (`{community}/feed`, the unified
  feed's paged collection).
- The `/actor?iri=…` and `/object?iri=…` deep-link routes (S2).
