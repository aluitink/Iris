# 39.2 — Community create

## Summary

Added a "Create a community" form to the `/communities` page. Users can now create new communities by providing a name, handle, and optional description. The form calls `CreateCommunityAsync`, which publishes a `Create` activity (containing a `Group`) to the user's outbox; the server's outbox-publish handler materializes the community.

## Changes

### `apps/Iris.Web/Components/Pages/Communities.razor`

- Added a "Create a community" card above the community list with three fields:
  - **Name** (required, max 100 chars) — the community's display name
  - **Handle** (required, max 63 chars, pattern `[a-z0-9\-]*`) — the community's identifier in its IRI
  - **Description** (optional, max 500 chars) — the community's summary
- The submit button is disabled until both name and handle are non-empty.
- On success: shows "Community created!", clears the form, and refreshes the community list.
- On failure: shows an error message with the HTTP status.
- Extracted community-list loading into `LoadCommunitiesAsync` for reuse after creation.

### `src/Iris.Client/IActivityPubClient.cs`

- Added optional `string? description = null` parameter to `CreateCommunityAsync`.

### `src/Iris.Client/ActivityPubClient.cs`

- `CreateCommunityAsync` now sets `Group.Summary` when a description is provided.
