# 39.3 — Settings page

## Summary

Added a `/settings` page with three tabs: Account, Password, and Communities. Added a "Settings" nav link to the main navigation.

## Changes

### `apps/Iris.Web/Components/Pages/Settings.razor` (new)

- `/settings` page, `[Authorize]`-gated.
- **Account tab** (default): shows the user's profile via `ActorProfile` component + a link to `/profile` for editing display name/description.
- **Password tab**: placeholder — "Password changes are not yet available. This feature is on the roadmap." with a disabled button.
- **Communities tab**: lists communities the user is a member of. Loads on first tab switch (lazy), searches all local communities via the search endpoint, then checks membership for each via `UiContext.IsMemberAsync`. Shows "Browse communities" link when empty.
- Uses the established tab pattern from `CommunityDetail.razor` (`tab-bar` / `tab` / `tab--active`).

### `apps/Iris.Web/Components/Layout/MainLayout.razor`

- Added `<a href="/settings">Settings</a>` to the signed-in nav, between Profile and Search.

### `tests/Iris.Web.Tests/ProductShellIntegrationTests.cs`

- 3 new integration tests:
  - `SettingsPage_SignedOut_RedirectsToLogin` — verifies the `[Authorize]` gate.
  - `SettingsPage_SignedIn_Returns200WithSettingsMarkup` — verifies the page renders with tab labels.
  - `SettingsPage_SignedIn_NavShowsSettingsLink` — verifies the nav includes the Settings link.

## Verification

- Live (Playwright):
  - Logged in as alice, navigated to `/settings`.
  - Account tab: shows alice's profile + "Edit your profile" link.
  - Password tab: shows placeholder text.
  - Communities tab: shows "You are not a member of any communities yet" (alice has no memberships in current DB state).
  - Nav shows "Settings" link.

## Decisions

- **Password change is a placeholder**: The data layer (`IUserAccountStore.UpdatePasswordHashAsync`) and `PasswordHasher` are already in place, but a full change-password flow (endpoint + UI + current-password verification) is a separate slice. The settings page shows a disabled button with a roadmap note.
- **Communities tab is lazy-loaded**: The membership check for each community involves a server round-trip per community (`IsMemberAsync` walks the `/members` collection). Loading this eagerly on page load would slow down the initial render. Instead, it loads only when the user switches to the Communities tab.
