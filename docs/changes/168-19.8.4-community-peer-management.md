# 168 — Phase 19.8.4: community peer management UI (outbound follow/unfollow)

## Summary

The `Community` page gains a **Peer management** card: enter a peer actor IRI and click **Community
follows** / **Community unfollows** to change the community's outbound follows (19.5.3 gap G-3 — the
community's outbound follow, signed as the community). This closes the "peer/follow management" part of
19.8.4, completing the community view's UI surfaces.

## What changed (code)

- **`samples/SampleBlazorClient/Pages/Community.razor`**
  - New **Peer management** card: a peer-actor-IRI text input + **Community follows** / **Community
    unfollows** buttons. The input is parsed with `Iri.TryParse`; on success the page calls
    `Session.GetClient().FollowAsync(communityIri, target)` (the community follows the peer — the
    activity's actor is the community, published to the community's outbox, signed as the community) and
    learns the minted follow id for a later undo; **Community unfollows** calls
    `UndoFollowAsync(communityIri, learnedFollowId)`. An invalid IRI or a missing learned id shows an
    inline error.
  - New `@code` state: `PeerIriInput`, `PeerBusy`, `PeerResult`, `PeerError`, `PeerFollowLearnedId`.
  - New methods: `PeerFollowAsync()` / `PeerUnfollowAsync()`.

## Key types / API

- `IActivityPubClient.FollowAsync(Iri actorId, Iri targetId, CancellationToken ct)` — with
  `actorId = communityIri`, builds a `Follow` with `actor = communityIri`, published to
  `communityIri.OutboxOf()` (the community outbox accepts `Follow`/`Undo`), signed as the community
  (the 19.5.3 outbound follow, gap G-3).
- `IActivityPubClient.UndoFollowAsync(Iri actorId, Iri originalFollowId, CancellationToken ct)` — the
  undo, referencing the learned follow id.
- **Signing as the community:** in the sample deployment (and the in-process test seed) the community's
  `publicKey` is the **primary actor's key** (alice's), so the session's client — signed as alice — can
  drive the community's outbound follow and the signature agrees with the activity's actor.

## New tests (2, all passing)

- **`tests/SampleBlazorClient.Tests/S19CommunityViewCompletenessTests.cs`** (+2):
  - `CommunityView_CommunityFollowsPeer_SignedAsCommunity_FollowsPeer` — `FollowAsync(communityIri,
    peerIri)` (signed as alice, the community's key) makes the community follow the peer; the

  - `CommunityView_CommunityFollowThenUnfollowPeer_RoundTrips` — the full follow→unfollow round-trip:
    the follow mints an id, the undo references it, and the community's `following` collection no longer
    contains the peer.
