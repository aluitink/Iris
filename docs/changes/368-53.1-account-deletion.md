# 53.1: Account Deletion (Self-Service + Admin)

## Summary

Added the ability to delete local accounts, both self-service (from Settings) and admin-assisted
(from the Admin Users page). Deletion is permanent and irreversible: all of the user's objects are
tombstoned, the actor is removed from the actor store, and the account row is deleted from the
database.

## Changes

### Server

- **`IUserAccountStore.DeleteAsync(Guid, CancellationToken)`** — new interface method; implemented
  in `InMemoryUserAccountStore` and `EfUserAccountStore`.
- **`IObjectStore.ListByActorAsync(Iri, CancellationToken)`** — new interface method to list all
  objects authored by a given actor; implemented in `InMemoryObjectStore`, `EfObjectStore`, and
  `FileBackedObjectStore`.
- **`AccountDeletionService`** (`apps/Iris.Web/Accounts/AccountDeletionService.cs`) — orchestrates
  the deletion: lists the actor's objects, tombstones each one, removes the actor from the actor
  store, and deletes the account row. Returns an `AccountDeletionResult` with a success flag and
  optional error message.
- **`DELETE /local/v1/account`** — self-service endpoint (cookie auth, `sub` claim). Registered in
  `MapAccountEndpoints`.
- **`DELETE /local/v1/admin/users/{id:guid}`** — admin endpoint (requires Admin role). Registered
  in `MapAdminEndpoints`.
- DI: `AccountDeletionService` registered as singleton in `WebAppFactory.cs`.

### UI (Blazor WASM)

- **Settings > Danger tab** — new tab with a two-step confirmation flow:
  1. "Delete my account" button → shows warning + "Are you absolutely sure?"
  2. "Yes, permanently delete my account" → calls `DELETE /local/v1/account`, redirects to `/logout`.
- **AdminUsers page** — new "Delete" button per user row:
  1. "Delete" → shows inline confirmation: "Permanently delete @username? This cannot be undone."
  2. "Delete" → calls `DELETE /local/v1/admin/users/{id}`, reloads the user list.
  - Success/error messages displayed at the top of the page.

### Verification

- Build clean (`dotnet build -warnaserror`).
- All 1,211 tests pass, 0 failures, 17 skipped.
