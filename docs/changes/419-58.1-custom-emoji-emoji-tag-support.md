# 58.1 — Custom emoji / Emoji tag support (F-27)

## Summary

Added read-path support for the `emoji` property (Mastodon/Pleroma custom emoji convention) on ActivityStreams content objects. Inbound notes that carry a top-level `emoji` array (each entry with `name`, `shortCode`, `staticUrl`/`url`) now:

1. **Round-trip** through the object store — the `emoji` array is preserved in the stored JSON document via `[JsonExtensionData]` with zero code changes (it was already round-tripping before this change; the new code *reads* it).
2. **Render** in the web UI — `ObjectView` displays each custom emoji as an `<img>` (when a URL is present) or a text fallback (shortcode in a `<span>`), placed below the content and above the action bar.

Outbound posts do not emit `emoji` (Iris has no custom-emoji upload feature yet); this slice is purely the inbound read path, which is what federation interop requires.

## Changes

### `IriExtensions.GetCustomEmojis()` (Core)

- New extension method on `IObject?` in `Iris.Core/Identity/IriExtensions.cs`.
- Reads the `emoji` array from `ExtensionData` (the `emoji` property is not a typed AS2 field, so it lands in `ExtensionData` on deserialization).
- Returns `IReadOnlyList<(string Name, string ShortCode, Iri? Url)>`.
- `shortCode` defaults to `:name:` when absent.
- `url` is resolved from `staticUrl` first, then `url`; `null` when neither is present.
- Entries without a `name` are skipped; non-object array entries are skipped; non-array `emoji` values return empty.

### `ObjectView` (Web Client)

- `ObjectView.razor.cs`: added `EmojiTags` property backed by `ResolveEmojiTags()`, which prefers `ActivityEmbeddedObject ?? Obj` (same pattern as media attachments — the emoji array lives on the Note, not on the wrapping Create activity).
- `ObjectView.razor`: added emoji rendering block after hashtag tags — a flex-wrapped `div.object-emojis` containing one `<img class="object-emoji">` per emoji with a URL (src rewritten same-origin via `RewriteMediaToSameOrigin`, `alt` and `title` set to the shortcode) or a `<span class="object-emoji-text">` text fallback.

### `app.css` (Web Client)

- `.object-emojis` — flex container, wrap, 0.25rem gap, top margin.
- `.object-emoji` — 1.5rem height, auto width, vertical-align middle.
- `.object-emoji-text` — 0.8rem font, muted color, monospace.

### Tests (Core)

- 12 new unit tests in `IriExtensionsTests` covering: null object, no `emoji` property, empty array, single emoji (name/shortcode/url), multiple emojis (order), missing `shortCode` (derived from name), missing `staticUrl` (falls back to `url`), no URLs (null Iri), entry without name (skipped), non-array `emoji` (empty), non-object array entries (skipped), full JSON serialization round-trip.
