# 54.27 — Public feed for logged-out visitors

## Objective

When a visitor lands on `https://iris.luit.ink/` while signed out, they should see a public timeline showing recent posts from all local actors, rather than just the hero + login links.

## Design

- **Server endpoint** `GET /ap/v1/public/feed` — no auth required. Returns a paged `OrderedCollection`/`OrderedCollectionPage` via `?page`/`?limit`, supports `?q=` (content/name substring) and `?type=` (activity type) filters. Served as a union of all local **Person** actors' outbox activities (Groups excluded — they have their own feed). Newest first, de-dup by item IRI, capped at 200 items.
- **`IPublicFeedService`/`PublicFeedService`** — new singleton service registered in `ActivityPubServerExtensions.cs`. Reads `IActorStore.ListActorsAsync`, filters to `Person` type, reads each actor's outbox via `IActivityStore.GetOutboxAsync`, concatenates, de-dups by IRI, caps at 200.
- **Client auth state** — `CookieAuthenticationStateProvider` now calls `GET /local/v1/session/public` (no auth) before the main session fetch. Attaches an `ActorClaims.PublicFeedIri` claim even when signed out. `IActorSessionAccessor.PublicFeedIri` exposes the value.
- **`PagedCollection` anonymous reads** — gained an `AnonymousHttpClient` parameter. When `Client` is null (signed out), falls back to plain HTTP via the anonymous client for public collections.
- **`Home.razor`** — the `<NotAuthorized>` template now renders the public feed via `<PagedCollection CollectionIri="feedIri" AnonymousHttpClient="Http">` under a "Public timeline" heading, below the existing hero.
