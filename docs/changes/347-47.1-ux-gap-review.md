## Defect fixed

### Boost ("Announce") card showed no content body

**Symptom:** On the home timeline and profile, a boosted post rendered only "Boosted" + avatar + author name — no content or link to the boosted object.

**Root cause:** The `Announce` activity in the feed carries its target as an `ILink` (IRI reference), not an embedded `IObject`. The `ActivityContent` property returned empty because `ActivityEmbeddedObject` was null (it only resolves `IObject` instances). Additionally, `AnnounceTargetIri` only resolved from `ActivityEmbeddedObject`, so it also returned null for link-only targets.

**Fix:**
1. `AnnounceTargetIri` now also resolves from a `ILink` in the activity's `Object` collection (fallback when no embedded object).
2. New `HasAnnounceContent` property checks whether the embedded object actually has renderable content.
3. `ObjectView.razor` boost card: when content exists, render it; otherwise render a "View boosted post →" link to the target object.

**Files changed:**
- `apps/Iris.Web.Client/Components/ObjectView.razor` — conditional content vs. link in boost card.
- `apps/Iris.Web.Client/Components/ObjectView.razor.cs` — `AnnounceTargetIri` link fallback; new `HasAnnounceContent` property.

**Verification:** Playwright — home timeline boost card now shows "View boosted post →" link; clicking it navigates to the correct object detail page. 0 console errors.
