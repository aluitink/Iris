# 53.5 — OrderedCollection Capability Advertisement + Feed Activity-Type Filtering

## Summary

Two related enhancements to the feed's `OrderedCollection` document:

1. **Capability advertisement**: The page-1 `OrderedCollection` document now carries `iris:refresh`, `iris:query`, and `iris:type` boolean flags advertising the query parameters the collection supports. Clients can read these flags to discover what filtering options are available without trial-and-error.

2. **`?type` activity-type filtering**: The feed endpoint (`GET /ap/v1/u/{handle}/feed`) now accepts a `?type=...` query parameter that filters the feed to only activities of that type (e.g. `?type=Create` to show only posts, excluding `Flag`/`Block`/`Like`/`Announce` activities).

## Changes

### `Iris.Core`
- `IrisExtensionTerms`: Added `Refresh`, `Query`, and `Type` constants for the new collection capability extensions.

### `Iris.Server`
- `IFollowFeedService.GetFeedAsync`: Added optional `activityType` parameter.
- `FeedService.GetFeedAsync`: Implements the type filter (`FilterFeedByType`), which matches activities by their `Type` property (case-sensitive, matching standard ActivityStreams type names).
- `ActivityPubServerExtensions.FollowFeedHandler`: Reads `?type` from the query string and passes it to the feed service. Passes capability flags + namespace to `BuildCollectionPageDocument`.
- `BuildCollectionPageDocument` / `SerializeCollectionPage`: Accept optional capability flags (`supportsRefresh`, `supportsQuery`, `supportsType`) and `namespaceIri`. When present, the page-1 `OrderedCollection` document emits `iris:refresh`, `iris:query`, `iris:type` as `true` booleans.
- `BuildNamespaceDocument`: Declares the three new terms in the `iris:` namespace context.

## Verification

- Build clean, all tests pass (1,211 passed, 0 failed, 17 skipped).
- Live-verified: `GET /ap/v1/u/alice/feed` returns the `OrderedCollection` with `"https://iris.luit.ink/ns#refresh": true`, `"https://iris.luit.ink/ns#query": true`, `"https://iris.luit.ink/ns#type": true`.
- `GET /ap/v1/u/alice/feed?type=Create` is accepted and returns the filtered feed (empty for a user with no follows, as expected).
