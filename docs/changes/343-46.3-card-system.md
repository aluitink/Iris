# 46.3: Card system

## Scope

Four design changes from the 46.1 audit:

1. **Post card hierarchy** (P1-2) — author handle is now `font-weight: 700` (was 600), content has `opacity: 0.92` to slightly reduce its visual weight. The author stands out from the content.
2. **Avatars in cards** (P2-6) — small 32px avatar circle (initial fallback) next to the handle in Create, Announce, and Note/Article cards in `ObjectView.razor`. Uses the first letter of the handle as a fallback (no image loading — keeps it fast and dependency-free).
3. **Button hierarchy** (P2-5) — introduced three button tiers:
   - **Primary** (default `--accent` blue): Follow, Post, Create community
   - **Secondary/Ghost** (`button--ghost`): Refresh, Mute, Report, Unblock, Unmute — transparent bg, muted text, border
   - **Warning** (`button--warning`): Block — amber/orange bg
   - **Destructive** (`button--danger`): Delete (already existed)
4. **Community row structure** (P3-12) — community list rows now use dedicated CSS classes (`.directory-item-name`, `.directory-item-handle`, `.directory-item-summary`) with clear visual hierarchy: bold name, muted handle, muted summary.

## Design decisions

- **Initial fallback, not image**: avatar circles use a colored initial (first letter of handle) instead of loading actor icon images. This avoids an extra HTTP request per card (12+ requests on a feed page) and keeps rendering synchronous. A future slice could layer in real icons with lazy loading.
- **768px breakpoint for hamburger** (from 46.2) is unchanged; no responsive changes in this slice.
- **`button--ghost` on `.btn`**: the moderation buttons use `.btn.btn-sm` (not `.button`), so the CSS needs `.btn.button--ghost` specificity to override the default `.btn` blue background.
- **Community rows**: replaced inline styles with dedicated CSS classes for consistency with the directory rows (which already had `.directory-item-*` classes).
