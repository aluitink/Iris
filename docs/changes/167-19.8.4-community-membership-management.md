# 167 — Phase 19.8.4: community membership management UI

## Summary

The `Community` page gains a **Manage membership** card: enter a member IRI and click **Add member** /
**Remove member** to change the community's member set, wired to the existing `AddMemberAsync` /
`RemoveMemberAsync` client one-call methods (19.6.1, change 161k). This closes the "membership
management" part of 19.8.4.

## What changed (code)

- **`samples/SampleBlazorClient/Pages/Community.razor`**
  - New **Manage membership** card: a member-IRI text input + **Add member** / **Remove member**
    buttons. The input is parsed with `Iri.TryParse`; on success the page calls
    `Session.GetClient().AddMemberAsync(communityIri, member)` or `RemoveMemberAsync(communityIri,
    member)` and shows the resulting status; an invalid IRI shows an inline error.
  - New `@code` state: `MemberIriInput`, `MemberBusy`, `MemberResult`, `MemberError`.
  - New methods: `AddMemberAsync()` / `RemoveMemberAsync()` (both delegate to `ManageMemberAsync(bool
    isAdd)`).

## Key types / API

- `IActivityPubClient.AddMemberAsync(Iri communityId, Iri memberId, CancellationToken ct)` /
  `RemoveMemberAsync(Iri communityId, Iri memberId, CancellationToken ct)` (19.6.1, change 161k):
  self-management membership — the `Add`/`Remove`'s `actor` is the community (the 19.5.2 gate), the
  request is signed as the community, and it is delivered to `communityId.InboxOf()`.
- **Signing as the community:** in the sample deployment (and the in-process test seed) the community's
  `publicKey` is the **primary actor's key** (alice's), so the session's client — signed as alice — can
  drive `AddMemberAsync`/`RemoveMemberAsync` and the self-management gate passes.

## New tests (2, all passing)

- **`tests/SampleBlazorClient.Tests/S19CommunityViewCompletenessTests.cs`** (+2):
  - `CommunityView_AddMember_SignedAsCommunity_AddsMember` — `AddMemberAsync` (signed as alice, the
    community's key) adds a new member; the member is recorded in the community's member set (the
    `{community}/members` collection the page reads).
  - `CommunityView_RemoveMember_SignedAsCommunity_RemovesMember` — `RemoveMemberAsync` removes a seeded
    member (bob); the member set no longer contains him (polled until gone).

## Verification

- Full test suite green: **1,394 tests, 0 failures** (SampleBlazorClient.Tests 155/155, was 153; +2).

## Scope note

- **Community creation** is **not** a UI slice: it has no federated ActivityStream activity type and no
  server route to accept one — it is a server-side/admin concern (deferred, decision recorded in
  change 161k).
- **Peer/follow management** (the community follows/unfollows a specific actor) remains open as a
  separate 19.8.4 slice.
