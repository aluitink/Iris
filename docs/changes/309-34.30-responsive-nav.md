# 34.30 — Responsive nav

**Phase 34 — UI polish & engagement**

## What changed

Added a `@media (max-width: 640px)` block to `app.css`:

- `.main-nav`: `flex-wrap: nowrap; overflow-x: auto; -webkit-overflow-scrolling: touch; scrollbar-width: none; max-width: 100%` — nav links scroll horizontally instead of wrapping.
- `.main-nav::-webkit-scrollbar`: hidden (WebKit scrollbar suppression).
- `.main-nav a`: `white-space: nowrap; font-size: 0.9rem` — links stay on one line, slightly smaller.
- `.main-header`: `flex-wrap: wrap; padding: 0.6rem 0.75rem` — brand can drop to its own line on very narrow screens.

## Decision

Chose horizontal scroll over a hamburger menu: the nav has 6–7 short links; a hamburger would add JS state, a toggle button, and an overlay for marginal benefit. Horizontal scroll is zero-JS, native, and works on all platforms.

## Verification

- 375px viewport: `.main-nav` computed `flexWrap: nowrap`, `overflowX: auto`; `.main-header` `flexWrap: wrap`
- 1024px viewport: `.main-nav` computed `flexWrap: wrap`, `overflowX: visible` (normal behavior preserved)
- Full fast suite green (1,599 passed)
