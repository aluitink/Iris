# 34.20 — Follow/unfollow cross-page round-trip fix

**Phase 34 — UI polish & engagement**

## Problem

The `FollowButton` component tracked the follow activity IRI (`_followActivityIri`) only locally. When a follow was made on one page (e.g. actor detail) and the user navigated to another page (e.g. directory), the new `FollowButton` instance had `_followActivityIri = null`. Clicking "Unfollow" on the new page silently failed because the code required a non-null `_followActivityIri` to call `UndoFollowAsync`.

## Fix

- **`UiContext.GetFollowActivityIriAsync(Iri targetIri)`** (new): scans the signed-in actor's outbox via `GetCollectionItemsAsync(me.OutboxOf())` for a `Follow` activity whose `object` resolves to `targetIri`. Returns the server-minted IRI of that activity, or null if not found.
- **`FollowButton.ToggleFollowAsync`**: when `IsFollowing` is true but `_followActivityIri` is null, falls back to `Ui.GetFollowActivityIriAsync(targetIri)` before calling `UndoFollowAsync`.

## Files changed

- `apps/Iris.Web/Ui/UiContext.cs` — added `GetFollowActivityIriAsync` method.
- `apps/Iris.Web/Components/FollowButton.razor` — `ToggleFollowAsync` now resolves the follow IRI from `UiContext` when the local cache is empty.

## Verification

- Verified live via MCP Playwright against the Docker stack:
  - Follow andrew from actor detail → button changes to "Unfollow".
  - Navigate to directory → andrew shows "Unfollow" (state persisted).
  - Click "Unfollow" from directory → button changes to "Follow" (cross-page unfollow works).
  - Follow andrew again from actor detail → navigate to directory → unfollow from directory → works.
- Full fast test suite green (1,599 passed, 0 failed).

## Decision

The outbox scan is O(n) where n is the number of outbox items. For a typical personal account this is small (tens of items). The scan only happens when the local cache is empty (cross-page navigation), not on every follow/unfollow. If performance becomes an issue at scale, a dedicated server endpoint (e.g. `GET /ap/v1/u/{handle}/follows/{target}`) could be added to return the follow activity IRI directly.
