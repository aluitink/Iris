# 34.23 — Landing page hero

**Phase 34 — UI polish & engagement**

## What was built

The signed-out landing page (`/`) now shows a clean centered hero instead of the old `<h1>` + card layout:
- Accent-colored "Iris" title (2.5rem, bold)
- Tagline in muted text
- Sign in / Create an account buttons

The redundant "Welcome to Iris" card heading and card wrapper are removed.

## Changes

### `apps/Iris.Web/Components/Pages/Home.razor`

- Removed the top-level `<h1>Iris</h1>` + `<p>` tagline (they were outside the `AuthorizeView`).
- Removed the `<div class="card">` wrapper and `<h2>Welcome to Iris</h2>` from the `<NotAuthorized>` section.
- Added a `<div class="landing-hero">` wrapper with `landing-title`, `landing-tagline`, and `landing-actions` classes.
- Signed-in view unchanged.

### `apps/Iris.Web/wwwroot/css/app.css`

- `.landing-hero` — centered, 3rem top padding.
- `.landing-title` — 2.5rem, bold, accent color.
- `.landing-tagline` — muted, max-width 480px, centered.
- `.landing-actions` — no margin.

## Design decisions

- **No icon/illustration.** The task asked for a clean hero; a text-only hero is the simplest and most maintainable. An SVG illustration can be added later (34.25 covers empty states with icons).
- **Accent color for the title.** Matches the brand link in the nav bar for visual consistency.
- **Signed-in view unchanged.** The task only addressed the signed-out experience.

## Verification

- Build: clean (0 warnings, 0 errors).
- Tests: full fast suite green (1,599 passed).
- Live (signed-out): centered "Iris" title + tagline + buttons, no card.
- Live (signed-in): "You're signed in." + quick links (unchanged).
