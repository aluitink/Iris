# 41.1 — Notification read-state + unread badge

## Summary

Adds notification read-state tracking and an unread count badge to the Iris Web UI:

- **"Mark all as read" button** on the `/notifications` page sets the account's `NotificationsReadAt` cursor to now.
- **Unread count badge** on the nav "Notifications" link shows the number of inbox items newer than the cursor, polled every 60 seconds.
- **Server endpoints** (cookie-auth gated):
  - `POST /local/v1/notifications/read` — advances the cursor and returns the (now-zero) unread count.
  - `GET /local/v1/notifications/unread-count` — returns the unread count without mutating state.

## Design decisions

### In-process service for Blazor (not HTTP)

The Blazor interactive server circuit cannot propagate the browser's auth cookie to a same-origin `HttpClient` call (the circuit is server-side; the cookie lives in the browser). Rather than solving this with `HttpApiClient` (which doesn't exist in this .NET 10 build) or manual cookie forwarding, the UI uses a new `NotificationService` that calls `IUserAccountStore` + `IPersistenceProvider` **directly in-process**. The HTTP endpoints remain for external consumers and the integration test suite.

### Unread count semantics

An inbox item is "unread" when its `Activity.Published` timestamp is strictly greater than the account's `NotificationsReadAt` cursor. When the cursor is `null` (never read), all items are unread. The count is computed by iterating the inbox and checking the `Published` field of each `Activity` item.

### Badge polling

The `NotificationBadge` component (rendered inside the nav "Notifications" link) polls the unread count every 60 seconds via a `System.Threading.Timer`. It only renders the badge span when the count is > 0 (caps display at "99+"). The timer is cancelled and disposed on component teardown.

## Tests

7 new integration tests in `Iris.Web.Tests`:

1. `UnreadCount_Unauthenticated_RedirectsToLogin` — unauthenticated GET → 302 /login.
2. `MarkRead_Unauthenticated_RedirectsToLogin` — unauthenticated POST → 302 /login.
3. `UnreadCount_NoInboxItems_ReturnsZero` — signed-in, empty inbox → `{"unread":0}`.
4. `UnreadCount_WithInboxItems_ReturnsCount` — two inbox items → `{"unread":2}`.
5. `MarkRead_SetsCursorAndResetsCount` — 1 unread → mark read → cursor set → 0 unread.
6. `MarkRead_OnlyCountsItemsAfterCursor` — mark read, add new item → 1 unread.
7. `NotificationService_GetUnreadCount_WorksInProcess` — in-process service: count → mark read → 0.

Full suite: 0 failures.
