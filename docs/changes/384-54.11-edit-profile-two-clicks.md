# 54.11 — Settings → Account → Edit profile takes two clicks

Phase 54 slice. From Settings' Account tab, "Edit your profile" linked to
`/profile`, which rendered the read-only `ActorProfile` view with its own
"Edit profile" button — the user had to click that button a second time to
reach `EditProfileForm`. The slice called for deep-linking straight to the
edit form so navigating from Settings lands directly on the editable screen.

## Change

[Settings.razor](apps/Iris.Web.Client/Components/Pages/Settings.razor):

- The "Edit your profile" link in the Account tab now points to
  **`/profile?edit=true`** (was `/profile`).

[Profile.razor](apps/Iris.Web.Client/Components/Pages/Profile.razor):

- Added a `[SupplyParameterFromQuery(Name = "edit")] private bool? EditRequested`
  parameter — Blazor auto-binds the `?edit=` query string to it.
- Added a one-shot `_pendingEdit` flag. When `EditRequested == true`,
  `OnParametersSet` sets `_pendingEdit = true`.
- `LoadActorAsync` (after the actor document is fetched) and a guard in
  `OnParametersSet` (for the cached-actor case where `ActorDoc` is already set)
  both call `ConsumePendingEdit()`, which sets `_editing = true` (the same
  state `StartEdit` sets), snapshots `_originalApproveFollowers`, and clears
  `SaveError`. The one-shot flag is consumed so a later re-render (e.g. after a
  save) does not re-enter edit mode.
- No change to the read-only path: `/profile` without `?edit=true` still shows
  the `ActorProfile` view + "Edit profile" button.

## Why `?edit=true` (query param) rather than a new route

A query parameter keeps a single `/profile` route (no new `@page` directive,
no routing ambiguity) and is the idiomatic Blazor way to carry a lightweight
"start in this mode" flag. `SupplyParameterFromQuery` binds it with zero
plumbing. The alternative (a dedicated `/profile/edit` route) would have
required a second `@page` attribute and duplicated the actor-load logic; the
query param reuses the existing page and its `OnParametersSet`/`LoadActorAsync`
flow untouched.
