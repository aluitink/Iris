## What changed

### `SharedHostFixture.ServerRefFor` (new)

```csharp
internal static readonly ConcurrentDictionary<IPersistenceProvider, TestServer> ServerRegistry = new();

public SharedHostFixture(ActivityPubHostOptions options)
{
    _server = ActivityPubHostFactory.Create(options);
    Persistence = options.Persistence;
    ServerRegistry[Persistence] = _server;  // ← register after Create returns
    _collectionCache = _server.Services.GetService<LocalCollectionPageCache>();
}

public static Func<TestServer> ServerRefFor(IPersistenceProvider persistence)
    => () => ServerRegistry[persistence];

public void Dispose()
{
    ServerRegistry.TryRemove(Persistence, out _);
    _server.Dispose();
}
```

**Why:** a self-fetcher / signed client needs a `Func<TestServer>` (a `LazyHandler` factory that calls
`server.CreateHandler()`), but the server is created **inside** the `SharedHostFixture` constructor
(`ActivityPubHostFactory.Create`), while the fetcher must be built **before** (it's in
`ActivityPubHostOptions.Fetcher`). The `LazyHandler` defers the `CreateHandler()` call until a request
is made, by which point the constructor has completed and registered the server in `ServerRegistry`.
`ServerRefFor(persistence)` returns a `Func<TestServer>` that resolves the server via the registry at
invocation time.

### `InteractionCollectionIntegrationTests` (converted)

- `[Collection("InteractionCollection")]` + `IAsyncLifetime` (ctor takes the fixture; `InitializeAsync`
  resets + reseeds; `DisposeAsync` disposes the `HttpClient`).
- `Seed` → `internal static SeedForFixture`; `BuildSelfFetcher` → `internal static`; `ActorIri` /
  `Host` / `Handle` → `internal`.
- The fixture builds the self-fetcher with `SharedHostFixture.ServerRefFor(persistence)`.
- `CreateClient` uses `_fixture.Server.CreateHandler()`.

## Why this is safe

- **Clean classes:** the per-method `Reset()` + reseed (or reset-only, for methods that seed
  themselves) gives each method a clean, freshly-seeded state. The `LocalCollectionPageCache` reset
  (added in the first partial) prevents stale page leakage between methods.
- **Self-fetcher class:** the fetcher's `InMemoryKeyStore` holds a **copy** of the key (via
  `PutKey`), and the key store is **not** cleared by `Reset()` (the host's signing infrastructure
  depends on it). The key is deterministic (same keyId after reseed), so the fetcher built at fixture
  construction time remains valid after resets. The `ServerRefFor` deferred lookup resolves the server
  at request time (after construction).
