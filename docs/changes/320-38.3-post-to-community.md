# 38.3 — Post to community

## What was built

The compose form (`/compose`) now accepts a `?community={iri}` query parameter. When present:

1. **Header:** The page title becomes "Post to {CommunityName}" and a context line shows "Posting to [community link]".
2. **Post logic:** The note is built with:
   - `attributedTo`: `[author, community]` (dual attribution — the author wrote it, the community hosts it)
   - `to`: `[community/followers, as:Public]` (delivered to the community's followers + public)
   - `content`: the user's text
   - `published`: UTC timestamp
3. **Button:** "Post to community" (vs. "Post" for normal notes).
4. **Success link:** After posting, "View community feed →" links to the community page (vs. "View your posts →" for normal posts).
5. **Community detail page:** A "＋ Post to this community" button appears below the header, linking to `/compose?community={iri}`.

## Key implementation details

- `Compose.razor` gains a `CommunityParam` query parameter and a `CommunityIri` derived property.
- `LoadCommunityNameAsync` fetches the community document to display its name in the compose header.
- `PostToCommunityAsync` builds a `KristofferStrube.ActivityStreams.Note` with dual `AttributedTo` and community followers in `To`, then calls `client.PostNoteAsync(actorId, note)` (the pre-built-note overload).
- The `Iri.FollowersOf()` extension derives the community's followers collection IRI.
- CSS: `.community-post-action`, `.compose-community-context`, `.compose-community-to`.

## Design decision

The post goes to the **author's outbox** (not the community's outbox) via `PostNoteAsync(actorId, note)`. The dual `attributedTo` means the server's `CreateActivityHandler` records the post in both the author's and the community's contexts. The community's **member feed** (which merges members' outboxes) will show this post once the author is a community member. The community's **followers feed** will show it because the `to` includes the community's followers collection.

This is consistent with how Mastodon handles community posts: the author's outbox is the canonical location, and the community's feed is a view over member outboxes.
