# 51.4 — Moderation queue (admin)

**Slice:** 51.4
**Status:** Complete
**Date:** 2026-09-08

## Summary

Added an admin-facing moderation queue at `/admin/moderation` that lists all flag edges
on the instance and allows the admin to dismiss (remove) individual flags.

## What changed

### Backend

- `IModerationStore` — added `GetAllFlagEdgesAsync(CancellationToken)` returning
  `IReadOnlyList<FlagEdge>` and a new `FlagEdge(Iri Flagger, Iri Flagged, DateTimeOffset CreatedAt)` record.
- `InMemoryModerationStore` — implemented `GetAllFlagEdgesAsync` using a
  `_flagTimestamps` dictionary populated in `RecordFlagAsync` and cleared in
  `RemoveFlagAsync`/`Clear`.
- `EfModerationStore` — implemented `GetAllFlagEdgesAsync` delegating to
  `EdgeStore.AllEdgesWithTimestampsAsync(EdgeKind.Flag)`.
- `FileBackedModerationStore` — implemented `GetAllFlagEdgesAsync` (timestamps
  default to `UtcNow` since the file format does not store them).
- `EdgeStore` — added `AllEdgesWithTimestampsAsync(EdgeKind, CancellationToken)`.
- `WebAppFactory` — added two admin endpoints:
  - `GET /local/v1/admin/flags` — returns all flag edges (Admin role).
  - `POST /local/v1/admin/flags/dismiss` — body `{flaggerIri, flaggedIri}`;
    removes the flag edge (Admin role). Uses a `DismissFlagRequest` record
    because IRIs contain slashes and cannot be reliably parsed from the URL path.

### Frontend (WASM)

- `AdminModeration.razor` — new page at `/admin/moderation`. Shows a table of
  flags (flagger, flagged actor link, date, dismiss button). Dismiss calls the
  POST endpoint and removes the row from the list.
- `MainLayout.razor` — added "Moderation" link to the footer.
