# 34.31 — Color & typography refinement

**Phase 34 — UI polish & engagement**

## What changed

- **Background**: `--bg` from `#0f1115` → `#111318`, `--panel` from `#171a21` → `#191d24` (slightly warmer, less harsh).
- **Heading hierarchy**: Added explicit `h1` (1.6rem/700), `h2` (1.35rem/700, -0.01em tracking), `h3` (1.1rem/600) styles with consistent line-height 1.3. Previously headings used browser defaults with no differentiation from body text weight.
- **Warm accent**: New `--accent-warm: #7c9fff` variable. Applied to: links (base color), nav link hover, brand text, `.object-type` label. The base `--accent` (#5b8cff) remains for buttons and primary actions.
- **Brand**: 1.25rem → 1.3rem, added -0.02em letter-spacing, uses warm accent.
- **Body**: line-height 1.5 → 1.6 for improved readability.
- **Links**: Added explicit `a:hover` with underline + shift to base accent.

## Decision

Two-tone accent (warm for text/links, base for buttons) creates visual hierarchy without adding a third color. The warm shade is lighter and more inviting for reading; the base shade is stronger for CTAs.
