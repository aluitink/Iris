# 319 — 37.1: Server actor-update handler

## Summary

`UpdateActivityHandler` now handles an actor updating their own profile document. When an inbound `Update` activity carries an embedded `Actor` whose IRI matches the updating actor's IRI, the handler refreshes the stored actor via `IActorStore` (merging name, summary, icon, endpoints) while preserving the `publicKey` and any `ExtensionData` entries the update does not override. The update is then propagated to the actor's remote followers.

## Changes

- **`src/Iris.Server/Inbox/UpdateActivityHandler.cs`** — `HandleAsync` now checks whether the embedded object is an `Actor` whose IRI equals the updating actor's IRI before falling through to the object-store path. If matched, `HandleActorUpdateAsync` (new private method) fetches the stored actor from `IActorStore`, merges the mutable fields from the update, preserves `publicKey`/`ExtensionData`, writes back via `PutActorAsync`, and propagates to remote followers via `IDeletePropagationService.PropagateUpdateAsync` when the actor is local.

## Security notes

- A remote actor cannot update a local actor's profile: the object IRI must match the updating actor's IRI, so a remote actor's `Update` with a different object IRI falls through to the object-store path (which requires the object to be stored + attributed to the updater).
- An update that does not carry a field leaves that field unchanged on the stored actor (merge semantics, not replace).
- `publicKey` is preserved from the stored actor unless the update explicitly overrides it via `ExtensionData`.

## Tests

4 new tests in `tests/Iris.Server.Tests/Inbox/UpdateActivityHandlerTests.cs`:

- `HandleAsync_LocalActorUpdatesOwnProfile_UpdatesStoredActor` — name + summary updated in `IActorStore`.
- `HandleAsync_LocalActorUpdatesOwnProfile_PropagatesToRemoteFollower` — remote follower's inbox receives the `Update`.
- `HandleAsync_LocalActorUpdatesOwnProfile_OnlyLocalFollowers_NoPropagation` — no delivery when all followers are local.
- `HandleAsync_RemoteActorUpdatesLocalActorProfile_NoOp` — a remote actor's `Update` targeting a local actor's IRI is rejected (object IRI ≠ updater IRI).
- `HandleAsync_ActorNotStored_NoOp` — an update for an unknown actor is a no-op.
