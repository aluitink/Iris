# 215 — 19.5.2: remote-actor join request → accept flow

**Phase:** 19.5 (community membership) / 19.5.2 (join lifecycle)

**Feature:** A gated community-membership lifecycle for remote actors. When a
community sets the `manuallyApprovesMembers` extension flag (analogous to
`manuallyApprovesFollowers`), an inbound `Join` activity from a remote actor
does NOT immediately grant membership. Instead, the request is recorded as
pending and surfaced in the community's outbox for the operator to `Accept` or
`Reject`. Communities without the flag retain the legacy auto-grant behavior.

**Components:**

1. **Store** — `ICommunityStore` gains four join-request methods
   (`AddJoinRequestAsync`/`RemoveJoinRequestAsync`/`HasJoinRequestAsync`/
   `GetJoinRequestsAsync`), implemented in `InMemoryCommunityStore` (concurrent
   dictionary) and `FileBackedCommunityStore` (JSON `joinRequests` section).

2. **Extension constant** — `ActivityPubServerConstants.ManuallyApprovesMembersExtensionName`
   (`"manuallyApprovesMembers"`), carried in the group's `ExtensionData`.

3. **Inbound gate** — `MembershipActivityHandler.AddMemberAsync` now checks the
   community's `manuallyApprovesMembers` flag when the activity is a `Join`.
   When gated, it records a pending join request instead of granting membership.
   `Offer`/`Invite` are unaffected (they remain auto-grant).

4. **Decision recording** — `RecordCommunityDecisionAsync` (new) dispatches a
   community-outbox `Accept`/`Reject` to the join-decision or follow-decision
   path based on the referenced activity's type. `RecordJoinDecisionLocalAsync`
   (new) handles the join case: `Accept` adds the requesting actor as a member
   and removes the pending request; `Reject` removes the pending request without
   granting membership.

5. **Client** — `IActivityPubClient` / `ActivityPubClient` gain three methods:
   - `RequestJoinAsync(actorId, communityIri)` — builds a `Join` and delivers
     it to the community's inbox.
   - `AcceptJoinAsync(communityIri, joinIri)` — builds an `Accept` (object =
     the Join) and publishes it to the community's outbox.
   - `RejectJoinAsync(communityIri, joinIri)` — builds a `Reject` (object =
     the Join) and publishes it to the community's outbox.
