# 47.4 — Performance & polish

Performance improvements and final visual polish: static-file caching, larger timeline page size, missing CSS variables, favicon, and button consistency.

## Changes

### 1. Static-file Cache-Control headers (high impact for repeat visits)

**File:** `WebAppFactory.cs`

**Before:** No `Cache-Control` headers on static files; `ServeUnknownFileTypes = true` (security smell).

**After:**
- `/_framework/*` (WASM runtime, fingerprinted per build): `public, max-age=31536000, immutable` — eliminates re-download of the multi-MB WASM payload on repeat visits.
- `*.css`, `*.js`: `public, max-age=86400` — 24h cache for non-fingerprinted assets.
- Removed `ServeUnknownFileTypes = true` (security hardening).

**Verified:** `curl -sI` confirms correct headers on `_framework/blazor.webassembly.js` and `css/app.css`.

### 2. Home timeline page size 5 → 20

**File:** `HomeTimeline.razor`

**Before:** `PageSize="5"` — with the `IsContentItem` filter discarding social activities (Follow, Like, etc.), users saw far fewer than 5 posts per "Load more" click.

**After:** `PageSize="20"` — all current test content loads in one fetch; no "Load more" button needed for typical timelines.

### 3. Missing CSS custom properties

**File:** `app.css` (`:root` block)

**Before:** `--surface`, `--fg`, `--hover`, `--card` were referenced but never defined, causing:
- Tab bar background transparent (should be `#1f242e`)
- Engagement menu text color falling back to inherited (should be `#e6e8ec`)
- No visible hover state on engagement menu items (should be `#262b36`)
- Engagement menu popup background missing (should be `#191d24`)

**After:** All four variables defined with appropriate dark-theme values.

### 4. Favicon

**File:** `favicon.svg`

**Before:** 1-byte empty file (browsers show a broken/blank tab icon).

**After:** 32×32 SVG matching the brand mark (blue circle + center dot, `#5b8cff`).

### 5. "Load more" button styling

**File:** `PagedCollection.razor`

**Before:** Bare `<button>` with no class (inconsistent with other secondary buttons).

**After:** `class="button button--secondary"` for visual consistency.
