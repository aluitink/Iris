# 53.3 — Instance Admin Dashboard

## Summary

Admins can now view an instance-level dashboard at `/admin/dashboard` showing local user count, post (object) count, and the 10 most recent registrations.

## Changes

### Endpoint

- **`GET /local/v1/admin/stats`** (admin-only) — returns `{ userCount, postCount, recentRegistrations: [{id, username, actorIri, role, createdAt}] }`.
  - User count: `IUserAccountStore.GetAllAsync()` length.
  - Post count: `IObjectStore.ListObjectsAsync()` filtered to exclude `Tombstone`s.
  - Recent registrations: top 10 accounts by `CreatedAt` descending.

### UI

- **`AdminDashboard.razor`** — new page at `/admin/dashboard` (admin-only via `Authorize(Policy = "Admin")`).
  - Two stat cards (users, posts) in a responsive grid.
  - Recent registrations table (handle, role badge, registration date).
- **Footer nav** — "Dashboard" link added alongside "Admin" and "Moderation".

### CSS

- `.stats-grid`, `.stat-card`, `.stat-value`, `.stat-label` classes in `app.css` for the stat card layout.

## Verification

- Build clean (`dotnet build -warnaserror`), all tests pass.
- Live API: `GET /local/v1/admin/stats` → `{ userCount: 2, postCount: 3, recentRegistrations: [bob, alice] }`.
- Live UI: dashboard renders stat cards (2 users, 3 posts) + recent registrations table with correct role badges.
