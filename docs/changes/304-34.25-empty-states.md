# 34.25 — Empty states with icons

**Phase 34 — UI polish & engagement**

## What was built

Empty states on the home timeline, notifications, and search pages now show an inline SVG icon + a friendly message instead of plain muted text. The home timeline empty state includes a "Browse the directory →" action link.

## Changes

### `apps/Iris.Web/Components/PagedCollection.razor`

- Added `EmptyContent` `RenderFragment` parameter. When provided, it replaces the plain `EmptyMessage` text in the empty state.
- The empty state is now wrapped in a `<div class="empty-state">` when `EmptyContent` is used.

### `apps/Iris.Web/Components/Pages/HomeTimeline.razor`

- Replaced `EmptyMessage` with an `EmptyContent` fragment: chat bubble SVG icon + "Your timeline is empty." + "Follow people to see their posts here." + "Browse the directory →" link.

### `apps/Iris.Web/Components/Pages/Notifications.razor`

- Replaced `EmptyMessage` with an `EmptyContent` fragment: bell SVG icon + "No notifications yet." + "When someone follows you, replies, or mentions you, it shows up here."

### `apps/Iris.Web/Components/Pages/Search.razor`

- Replaced the plain "No matches." text with an `empty-state` div: magnifying glass SVG icon + "No matches found." + "Try a different handle or search term."

### `apps/Iris.Web/wwwroot/css/app.css`

- `.empty-state` — centered, 2rem padding, muted color.
- `.empty-state svg` — 48px, 0.5 opacity, 0.75rem bottom margin.
- `.empty-state p` — no bottom margin except last.
- `.empty-state a` — accent color, no underline (underline on hover).

## Design decisions

- **`RenderFragment` over a `string` icon parameter.** Each page can provide fully custom empty state markup (different icons, messages, action links) without the component needing to know about specific icons or links.
- **Inline SVGs.** No external icon library needed. The three icons (chat bubble, bell, magnifying glass) are simple single-path SVGs that render crisply at any size.
- **Backward compatible.** Pages that don't provide `EmptyContent` still use the plain `EmptyMessage` text (the profile page's "You haven't posted anything yet" and actor detail's "No posts yet." are unchanged).
