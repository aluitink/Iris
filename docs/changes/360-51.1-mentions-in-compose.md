# 51.1 — Mentions in compose

**Phase 51, Slice 1: Feature completion — `@handle` mentions in the compose flow.**

## What

Typing `@handle` in a composed note, reply, community post, or article now produces a
proper ActivityPub `Mention` tag on the published object. The tag's `href` is the
mentioned actor's IRI (same-instance only — cross-instance WebFinger lookups are
deferred). A single `Mention` serializes as a bare string (the one-or-many converter);
multiple mentions serialize as an array.

## Files changed

- `src/Iris.Core/Compose/ComposeNote.cs` — `Build()` accepts an optional
  `IEnumerable<Iri>? mentions` parameter; each IRI becomes a `Mention { Href = i.Uri }`
  entry in the note's `Tag` list.
- `apps/Iris.Web.Client/Components/Pages/Compose.razor` — added `DetectMentionsAsync`
  (regex `(?<=^|\s)@([a-zA-Z0-9_]+)`, resolved against the signed-in actor's origin).
  Wired into all four post paths: reply, community, article, and note.
  **Fix:** `Uri.GetLeftPart(UriPartial.Authority)` already includes the scheme, so the
  original `https://{baseOrigin}` produced a doubled-protocol IRI
  (`https://https//iris.luit.ink/...`). Corrected to `{baseOrigin}`.
