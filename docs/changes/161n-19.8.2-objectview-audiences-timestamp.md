# 161n — 19.8.2 rendered object view quality: audiences + published timestamp

## Summary

Phase 19.8.2 (**rendered object view quality**), first slice: the object view (`ObjectView`, rendered by
`ObjectPage`) now shows the object's **audience** (its `to` + `cc` recipients, as links to each
recipient's actor page, the `as:Public` sentinel excluded) and its **`published` timestamp** (rendered
as a local time). This closes two of the read-side quality items on 19.8.2; the reply-chain /
conversations view, like/boost counts, and the remote canonical-URL link remain open (they depend on
19.2.4 and the 19.1.x remote-read surface).

## What changed

- **`src/Iris.Core/Identity/IriExtensions.cs`**
  - `GetAudienceIris(this IObject?)` — the shared boundary read for an object's audience: the union of
    `to` + `cc`, de-duplicated (case-insensitive, first-seen order), with the public-audience sentinel
    (`as:Public` / the W3 `activitystreams#Public` IRI, http or https) excluded. Reads `to` first, then
    `cc`; returns an empty list when there is no audience or only the sentinel. Each entry is an
    `IObjectOrLink` (a `Link` to an actor/community IRI, or an embedded object carrying it in `Id`),
    resolved via the existing `ResolveObjectIri`.
  - `IsPublicAudience(this Iri)` — reports whether an IRI is the well-known public-audience sentinel.
- **`samples/SampleBlazorClient/Components/ObjectView.razor`**
  - After the content block, renders each audience IRI as a `to` row linking to the recipient's actor
    page (`/actor?iri=…`, display = the handle), and — when present — a `published` row showing the
    local time (full RFC-3339 value in the element's `title` for stable inspection).
  - New `@code` properties: `AudienceIris` (`Obj?.GetAudienceIris()`) and `Published` (`Obj?.Published`).

## Tests

- **`tests/Iris.Core.Tests/Identity/IriExtensionsTests.cs`** (new `GetAudienceIris` / `IsPublicAudience`
  cases): to-then-cc ordering; public-sentinel exclusion (both in `to` and as the only audience);
  de-duplication of a repeated audience; an embedded audience object resolving its `Id`; no-audience →
  empty; null → empty; and an `IsPublicAudience` theory covering `as:Public`, the https/http W3 IRI, and
  a non-public actor IRI.
- **`tests/SampleBlazorClient.Tests/S19ObjectViewQualityTests.cs`** (new, in-process **bUnit** render
  tests, mirroring the S2 deep-linking pattern): a note with `to`+`cc` renders both as `/actor?iri=…`
  links; the audience link's text is the recipient handle; a note with only the public sentinel renders
  **no** audience link; a note with `published` renders a `.object-published` row whose `title` is the
  RFC-3339 value; a note without `published` renders no timestamp row; a note without an audience
  renders no `.object-audience` row; and a combined case rendering both.
