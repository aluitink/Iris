# 55.3 — Operator Runbook + API Reference Polish

## Summary

Wrote `docs/OPERATOR_RUNBOOK.md` — a consolidated, concise operator-facing reference that
ties together the existing deployment docs (`apps/Iris.Web/deploy/`) with day-to-day
operational guidance, troubleshooting, and upgrade procedures.

Verified the OpenAPI spec is correctly generated: **61 endpoints** (up from the "44+"
mentioned in the roadmap), OpenAPI 3.1.1, auto-generated from minimal-API metadata. The
spec is served at `GET /openapi/v1.json` with a Swagger UI at `/api/`.

## Deliverables

### `docs/OPERATOR_RUNBOOK.md` (new)

Consolidated operator reference covering:
- **Architecture at a Glance** — component diagram, volume table, loss-impact matrix
- **Configuration** — all env vars with defaults and purposes
- **Day-to-Day Operations** — health checks, Docker status, restart, delivery metrics
- **Backup and Restore** — summary + pointer to `deploy/BACKUP.md`
- **Monitoring and Alerting** — key log patterns to alert on, Prometheus scrape
- **Troubleshooting** — 7 common issues with diagnostic steps and fixes:
  - Session invalidation after restart (DP keys)
  - Images 404 after restart (media volume)
  - Federation not working (checklist)
  - Wrong remote actor IRI (55.2 fix reference)
  - Delivery queue growing
  - 503 from health endpoint
  - (implicit) Postgres connectivity
- **Upgrades** — standard upgrade + rollback procedures
- **Security Notes** — non-root, TLS, cookie auth, rate limiting, CORS, body caps
- **File Reference** — all deployment/config files
