## Summary

Phase 20.7 is the **capstone**: a Playwright-MCP-driven manual test plan that confirms every 20.x
capability **from a user's seat** — the sample Blazor WASM UI plus wire evidence — on the intended
`docker-compose.yml` production-shape stack (iris-a :8081, iris-b :8082, iris-ui :8090/:8088, fresh

`iris-dev1.luit.ink`).

## Defects found and fixed during the plan

1. **Announce-edge bug (20.4e)** — the local outbox-write `Announce` branch in `OutboxPublishHandler`
   never recorded the local announce edge. Fixed: `RecordAnnounceLocalAsync` + `RemoveAnnounceLocalAsync`
   + `Undo(Announce)` case. 2 regression tests. **Committed as `8b3329e`.** Confirmed live: Boost →
   `/shares` `totalItems: 1`.

2. **Single-element `items` serialization bug (20.3/20.4)** — the `KristofferStrube.ActivityStreams`
   library's `OneOrMultipleConverter` collapses a 1-element `Items` list to a bare JSON string. Fixed:
   `BuildCollectionPageDocument` now calls a `SerializeCollectionPage` helper (manual `Utf8JsonWriter`
   envelope, always-array `items`, per-item serialization via `ActivityJson.Options`). **Committed as
   `3d88c09`.** Regression test `SingleItemCollection_ItemsIsAlwaysAJsonArray`.

## GAPs / sharp edges (not defects)

- **UI count display does not auto-re-fetch** after Like/Boost (updates on re-load only). Cosmetic.
- **Markdown renderer subset** does not include blockquotes (`>`) or lists mixed into non-list blocks
  without blank-line separation. Documented in the 20.4c change doc.
- **Default logon base URL `iris.luit.ink` is GET-only** (external nginx). Browser writes 405 through
  that host; the user must dial the API FQDN (`iris-dev1.luit.ink`) for writes to succeed. This is a
  deployment/UX sharp edge. The UI could default the logon base to the actor's WebFinger-resolved host
  (which is POST-allowing) to avoid the 405.
