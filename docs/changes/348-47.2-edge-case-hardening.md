# 47.2 — Edge-case hardening

Verified error states, empty states, and loading indicators across all pages. Fixed raw .NET exception messages leaking to the UI.

## Defects fixed

### Raw exception messages shown to users

**Symptom:** Navigating to `/object?iri=not-a-valid-iri` (or any invalid IRI) showed the raw .NET resource string `net_http_client_invalid_requesturi` in the error card.

**Root cause:** Multiple pages (`ObjectDetail`, `ActorDetail`, `CommunityDetail`, `PagedCollection`) caught exceptions and set `LoadError = ex.Message`, which for `HttpRequestException`/`UriFormatException` exposes .NET internal resource keys.

**Fix:** Replaced raw `ex.Message` with user-friendly error messages in all load paths:
- `ObjectDetail.razor`: "Failed to load object. It may not exist or the server is unreachable."
- `ActorDetail.razor`: "Failed to load actor. It may not exist or the server is unreachable."
- `CommunityDetail.razor`: "Failed to load community. It may not exist or the server is unreachable."
- `PagedCollection.razor` (3 catch sites): "Failed to load. Please try again." / "Failed to load more items. Please try again." / "Failed to refresh. Please try again."

**Files changed:**
- `apps/Iris.Web.Client/Components/Pages/ObjectDetail.razor`
- `apps/Iris.Web.Client/Components/Pages/ActorDetail.razor`
- `apps/Iris.Web.Client/Components/Pages/CommunityDetail.razor`
- `apps/Iris.Web.Client/Components/PagedCollection.razor`
