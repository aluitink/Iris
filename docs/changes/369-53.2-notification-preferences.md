# 53.2 — Notification Preferences (Mute/Follow Notification Toggles Per User)

## Summary

Users can now control which notification types they receive and mute specific actors' notifications. Preferences are stored per-user and applied server-side to filter the inbox before unread counts and mark-read operations.

## Changes

### Model

- **`NotificationPreferences`** (new, in `UserAccount.cs`):
  - `DisabledTypes: HashSet<string>` — Activity types to suppress (e.g. "Like", "Follow", "Announce", "Create").
  - `MutedActors: HashSet<string>` — Actor IRIs whose notifications are hidden.
- **`UserAccount.NotificationPrefs`** — nullable `NotificationPreferences?` property on the existing account model.

### Persistence

- **`UserAccountEntity.NotificationPrefsJson`** — nullable `string` column storing JSON-serialized preferences.
- **EF mapping** in `EfUserAccountStore.ToEntity`/`ToModel` — serializes/deserializes the JSON column.
- **In-memory `clone()`** in `InMemoryUserAccountStore` — deep-copies the `NotificationPrefs` set.
- **EF migration** `AddNotificationPrefs` — adds the nullable `NotificationPrefsJson` column.

### Store API

- **`IUserAccountStore.UpdateNotificationPrefsAsync(Guid userId, NotificationPreferences? prefs, CancellationToken)`** — replaces the user's notification preferences. Implemented in both `EfUserAccountStore` and `InMemoryUserAccountStore`.

### Endpoints (in `MapNotificationEndpoints`)

- **`GET /local/v1/account/notification-preferences`** — returns `{ disabledTypes: string[], mutedActors: string[] }`. Defaults to empty sets if no prefs are set.
- **`PUT /local/v1/account/notification-preferences`** — replaces the user's preferences. Accepts `{ disabledTypes?: string[], mutedActors?: string[] }` body.
- **`FilterInboxByPrefs`** helper — filters a list of inbox items by removing activities whose type is in `DisabledTypes` or whose actor IRI is in `MutedActors`. Applied to both the unread-count and mark-read endpoints.

### UI (Settings > Notifications tab)

- **Notification types** — checkboxes for:
  - New followers (Follow)
  - Likes on your posts (Like)
  - Boosts / shares (Announce)
  - Replies to your posts (Create)
- **Muted actors** — list of muted actors with Unmute buttons; input field + Mute button to add an actor by IRI.
- Saving is immediate (PUT on each toggle change or mute/unmute action).

### Client code (`Settings.razor`)

- `NotifPrefsModel` — holds `DisabledTypes` and `MutedActors` in the UI state.
- `LoadNotifPrefsAsync` — fetches current prefs on tab open.
- `ToggleNotifType(string type)` — toggles a type and saves.
- `AddMutedActor(string iri)` / `RemoveMutedActor(string iri)` — manages muted actor list.
- `SaveNotifPrefsAsync` — PUTs the current state.
