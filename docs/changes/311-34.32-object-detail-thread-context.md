# 34.32 — Object detail: show the full thread

**Phase 34 — UI polish & engagement**

## What changed

`ObjectDetail.razor` now shows the parent note's context when viewing a reply:

- `LoadParentAsync` calls `ObjectDoc.GetParentIri()` (existing F-12 extension) and, when non-null, fetches the parent via `GetObjectAsync`.
- `ParentDoc` holds the resolved parent object.
- `ParentAuthor` extracts the author handle from the parent's `AttributedTo` (handles both embedded `Actor` and `Link` cases; falls back to the last IRI segment).
- `ParentPreview` strips HTML from the parent's `Content` and truncates to 200 chars.
- `ParentHref` links to the parent's object detail page.
- UI: a `.object-parent-context` card (dark bg, left accent border) renders above the main note with "In reply to [author]" label + truncated parent content.

## Decision

Show only the immediate parent (one level up), not the full thread chain. Fetching the entire ancestry would require N sequential fetches and is overkill for a lightweight detail view. The parent link allows the user to drill deeper if they want.
