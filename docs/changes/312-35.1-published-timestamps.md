# 35.1 — Server: set `published` timestamp on activities

**Phase 35 — Timeline actions & content completeness**

## What changed

Activities and objects now carry a `published` timestamp, making relative time ("just now", "2m ago") visible on all timeline cards and notifications.

### `ActivityPubServerExtensions.MintActivityIds`
- Sets `activity.Published = DateTime.UtcNow` when the activity has no `Published` (outbox path: actor + community).
- Sets `embedded.Published = DateTime.UtcNow` on embedded Create objects (Notes) when absent.

### `InboxProcessor.ProcessAsync`
- Sets `delivery.Activity.Published = DateTime.UtcNow` as a fallback for inbound activities that lack a timestamp (defensive; well-behaved remote servers include `published`).

### `CreateActivityHandler.StoreEmbeddedObjectAsync`
- Sets `embedded.Published` from the activity's `Published` (or `DateTime.UtcNow`) when the stored object lacks one.

## Decision

Use `DateTime.UtcNow` (not `DateTimeOffset.UtcNow`) to match the ActivityStreams library's `DateTime?` property type. The timestamp is set only when absent — a client or remote server that provides its own `published` is respected.
