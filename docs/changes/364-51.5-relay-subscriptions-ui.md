# 51.5 — Relay subscriptions UI (settings)

**Slice:** 51.5
**Status:** Complete
**Date:** 2026-09-08

## Summary

Added a "Relays" tab to the Settings page (`/settings`) that lets users list,
subscribe to, and unsubscribe from ActivityPub relay (fan-out server) subscriptions.
The server and client infrastructure (F-06) was already complete; this slice is purely
the production UI.

## What changed

### Frontend (WASM)

- `Settings.razor` — added a 5th "Relays" tab between Communities and Moderation:
  - Lists current relay subscriptions (host link + full URL + Remove button).
  - Input field for a relay URL + Subscribe button.
  - Validates that the input is a valid http(s) URL before calling the API.
  - Uses `CollectionQuery { BypassCache = true }` on re-reads after writes to
    avoid the 60s server-side collection page cache.
  - Lazy-loads on first tab activation (consistent with other tabs).
  - `@using Iris.Client.Collections` added for `CollectionQuery`.
