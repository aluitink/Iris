# 54.28 — Community profile page: owner icon/image + owners list + promote/demote

**Date:** 2026-09-09
**Branch:** `phase-32-production-app`

## Summary

Added community profile page features:
1. **Community icon upload** — the community owner can set an icon/image for the community via the Edit Community form (reuses the media upload flow from 54.12).
2. **Owners tab** — the community owner can view the list of owners (the Group's `AttributedTo` entries).
3. **Promote/Demote** — owners can promote a member to owner (adds the actor's IRI to `AttributedTo`) or demote an owner (removes from `AttributedTo`; the last owner cannot be demoted).
4. **Cookie-auth fix for local moderation** — `VerifyCommunityCreatorAsync` now accepts the Blazor WASM session cookie (`actor_iri` claim) in addition to Basic auth, fixing 403s on all community local-moderation endpoints (owners, join requests, member removal) from the browser.

## Design

- **Ownership model:** The Group's `AttributedTo` IS the owner list. No separate `iris:` extension property. `VerifyCommunityCreatorAsync` already iterates all `AttributedTo` entries for auth.
- **Promote:** Add the actor's IRI to `AttributedTo`. 409 if already an owner. The target must be a community member.
- **Demote:** Remove the actor's IRI from `AttributedTo`. 400 if it would leave zero owners. 404 if the actor is not currently an owner.
- **Icon:** Stored as the Group's `icon` property (a `Link` to the media IRI). Uploaded via `POST /local/v1/u/{handle}/media` (the existing media upload endpoint), then set via a community `Update` activity.

## Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/local/v1/c/{name}/owners` | List owner IRIs (owner-only). Returns JSON array. |
| POST | `/local/v1/c/{name}/owners/promote/{**actorIri}` | Promote a member to owner (owner-only). 409 if already owner. |
| POST | `/local/v1/c/{name}/owners/demote/{**actorIri}` | Demote an owner (owner-only). 400 if last owner. |
