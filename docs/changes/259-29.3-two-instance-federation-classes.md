## What changed

### `SharedTwoHostFixture` (new, in `Iris.Testing`)

A per-xunit-collection fixture that builds two in-process `TestServer` hosts ONCE and shares them
across every test method in the collection. Mirrors `SharedHostFixture` but for a pair of
cross-wired hosts (A delivers to B, B delivers to A; each fetcher routes by host IRI).

- `ServerA` / `ServerB`: the shared hosts.
- `PersistenceA` / `PersistenceB`: the hosts' persistence providers.
- `Reset()`: clears both persistence stores + both collection-page response caches. Key stores
  are left intact (the hosts' signing infrastructure depends on them).
- Protected tuple-ctor convenience: `protected SharedTwoHostFixture((ActivityPubHostOptions A,
  ActivityPubHostOptions B) options)` — for derived fixtures that build both options in a single
  method (so they can share persistence instances and cross-reference each other's servers via
  `ServerRefFor`).

### Conversion pattern

1. The **fixture** (`*SharedHost : SharedTwoHostFixture`) has a static `BuildOptions()` method that:
   - Creates both `InMemoryPersistenceProvider`s.
   - Seeds actors/communities with keys (`SeedPersonWithKey` / `SeedCommunityWithKey`).
   - Gets `ServerRefFor` closures for both persistence instances.
   - Builds both `ActivityPubHostOptions` with cross-wired `DeliveryTransport`
     (`() => new LazyHandler(() => serverBRef().CreateHandler())`) and `Fetcher`
     (`RoutingFetcher` with `LazyHandler` per host).
   - Returns the tuple `(optionsA, optionsB)`.
2. The **test class** takes the fixture, creates `HttpClient`s, sets key fields to `null!`.
3. `InitializeAsync` calls `_fixture.Reset()` + `SeedForFixture(_aPersistence, _bPersistence)`
   (which uses `SeedPersonWithExistingKey` / `SeedCommunityWithExistingKey`), then re-fetches
   the key objects from the persistence key stores.
4. Test methods use `_fixture.ServerA` / `_fixture.ServerB` (not `_a` / `_b`).
5. Helper methods (`BuildIdentity`, `BuildFetcherFor`, `RoutingFetcher`, etc.) are made `internal`.

  alice + iris + bob + lumen.
