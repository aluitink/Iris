# 53.4 — Fix Post-Login Current-User Context Race

## Summary

After login, navigating to `/home` showed a perpetual "Loading…" spinner (the feed never populated) until a manual Refresh click. Root cause: `PagedCollection` fired its initial load in `OnParametersSet` when `CollectionIri` first appeared, even though `Client` was still null (the session's signing key was still loading). The `_loadedFor` tracker was set, so when `Client` became available on the next render, `OnParametersSet` didn't re-trigger the load.

## Fix

`PagedCollection.OnParametersSet` now resets `_loadedFor = null` when `Client` is null (and returns early without firing the load). When `Client` transitions from null to non-null, `_loadedFor` is null, so the initial load fires correctly.

- Build clean, all tests pass (1,211 passed, 0 failed, 17 skipped).
- Live-verified: after login → navigate to `/home`, the feed loads on first paint (shows empty state for a user with no follows, not a perpetual spinner).
