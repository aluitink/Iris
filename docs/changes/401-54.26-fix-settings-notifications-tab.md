# 54.26 — Fix Settings → Notifications tab ("cannot load" error)

## Problem

The Settings → Notifications tab showed a "cannot load" error when clicked. The tab attempted to fetch notification mute preferences via `GET /local/v1/account/notification-preferences`, but the endpoint did not exist.

## Root Cause

The notification preferences endpoints (`GET`/`PUT /local/v1/account/notification-preferences`) were already implemented in `WebAppFactory.cs` (lines 608, 633) by a prior commit. The "cannot load" error was caused by a stale WASM bundle cached in the browser's immutable cache. After clearing the browser cache and reloading, the tab loads correctly.

## Fix

No code changes were required. The issue was resolved by clearing the browser's immutable WASM cache (via CDP `Network.clearBrowserCache` + `Network.clearBrowserCookies`).
