# 54.25 — No Reply Count Shown on Replied-To Items

## Problem

A post with replies didn't show a reply count anywhere in the UI. The `EngagementBar`
rendered Like and Boost buttons with their counts (from `iris:likedCount` /
`iris:sharedCount`), but the Reply button had no count — even though the server
already stamps `iris:repliedCount` onto every content object (since 54.8) and the
client already has a `GetRepliedCount()` extension method.

## Solution

In `EngagementBar.razor`:

1. Added a `_replyCount` field.
2. In the fast path of `OnParametersSetAsync` (where `iris:likedCount` and
   `iris:sharedCount` are seeded from the object's extension data), also seed
   `_replyCount` from `obj.GetRepliedCount(ns) ?? 0`.
3. In the Reply button's markup, conditionally render a
   `<span class="engagement-count">@_replyCount</span>` when `_replyCount > 0`.

The reply count is only shown when it's non-zero (matching the Like/Boost buttons
which always show their count, even when zero — but a reply count of zero is
informational noise on every post, whereas a like/boost count of zero at least
confirms the user hasn't engaged).
