# 46.5 — Mobile layout

## Scope

Address P1-1 (mobile layout) and P3-13 (compose empty space) from the 46.1 design audit. Also fix P1-3 (profile "Your posts" showing non-content activities as timestamp-only rows).

## Changes

### Profile.razor

- **P1-3 fix**: Added `ItemFilter="IsContentItem"` to the "Your posts" `PagedCollection` tab. Added `IsContentItem(IObject?)` method that returns true only for `Create` activities whose object is a `Note` or `Article`. This excludes Follow, Accept, Reject, Like, Announce, Undo, and Delete activities that were rendering as timestamp-only rows.

### Compose.razor

- **P3-13 fix**: Added a "Formatting tips" card below the compose form with four tips: @handle mentions, #hashtags, Note vs Article distinction, and content warning behavior. Fills the previously empty space below the form on mobile.

### app.css (client + server-side copy)

- **Mobile media query** (`@media (max-width: 768px)`):
  - Reduced `.main-content` padding to 12px
  - Smaller h1 (1.5rem) / h2 (1.25rem)
  - `.page-header-row` stacks vertically
  - Reduced `.card` padding to 12px
  - Smaller `.object-detail .object-content` font
  - `.actor-detail-header` stacks vertically
  - `.directory-item` stacks vertically with button aligned right
- **Compose tips**: `.compose-tips` card styling, `.compose-tips-list` with compact bullet styling.

## Design decisions

- **Profile filter reuses `IsContentItem` pattern** from `HomeTimeline.razor` — consistent behavior across the app: "posts" means content objects (Notes/Articles), not all activity types.
- **Compose tips are static** — no dynamic content. Four concise tips cover the main formatting features. Positioned below the form so they don't compete with the primary CTA.
