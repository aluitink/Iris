## What changed

### Per-class details

- **OutboxAnnounceFanOut** (5): The tests sign an `Announce`/`Undo` request as alice and POST it to A's
  outbox (`/ap/v1/u/alice/outbox`); A's server records the Announce in alice's outbox, records the local
  boost edge (decision 056 (d)), and federates the Announce to bob's inbox on B (F-15). B validates the
  signature against alice's actor document (fetched from A) and stores the Announce. The fixture seeds
  alice + bob with keys ONCE; A's identity + `RoutingFetcher` (routes by host IRI to A or B) +
  `DeliveryTransport` to B; B's fetcher reaches A (lazily, via `LazyHandler`). The bob→alice follow edge
  is recorded on A in `SeedForFixture`.

### Test breakdown

1. `OutboxPublish_AnnounceWithRemoteFollower_FederatesToFollower` — Announce federated to bob
2. `OutboxPublish_AnnounceWithNoRemoteFollowers_SurfacesLocallyOnly` — dave (no followers) surfaces locally only
3. `OutboxPublish_Announce_RecordsLocalBoostEdge` — local boost edge recorded (decision 056 (d))
4. `OutboxPublish_UndoAnnounce_RemovesLocalBoostEdge` — Undo(Announce) removes the local boost edge
5. `OutboxPublish_AnnounceWithBlockedRemoteFollower_SkipsBlocked` — blocked bob does not receive
