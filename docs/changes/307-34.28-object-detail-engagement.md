# 34.28 — Object detail: show like count + boost count

**Phase 34 — UI polish & engagement**

## What changed

`ObjectDetail.razor` now fetches the `/likes` and `/shares` collections for the displayed object and shows an engagement line under the note when either count is non-zero.

- `LoadEngagementAsync` calls `client.GetLikesAsync(iri, ...)` and `client.GetSharesAsync(iri, ...)` and counts the yielded items.
- `EngagementText` property returns `"N likes · M boosts"` (or just one part) when counts > 0, or `null` when both are 0 (no noise).
- Rendered in a `.object-detail-engagement` div between the note and the Reply button, styled with a top border, muted color, 0.85rem font.

## Decision

Show nothing when both counts are 0 — an empty engagement line adds visual noise without information. The line appears as soon as the object receives its first like or boost.

## Verification

Full fast suite green (1,599 passed). Live verification: object detail page loads correctly with no engagement line (no likes/boosts yet on the test object). The `GetLikesAsync`/`GetSharesAsync` calls succeed silently (0 items yielded).
