# 35.6 — Compose character count + content type selector

**Phase 35 — Timeline actions & content completeness** (final item)

## What was built

Two additions to the compose page:

1. **Character counter** — displays `N/500` below the textarea, right-aligned. Turns red (`.compose-char-count--over`) when the count exceeds 500. Updates in real-time as the user types (via `@bind="Content"` → `Content.Length`).

2. **Content type selector** — a dropdown with "Note" (default) and "Article (long-form)" options. Hidden when composing a reply (replies are always Notes). When "Article" is selected, the post constructs an ActivityStreams `Article` object (with `attributedTo`, `to`, `content`, `published`) wrapped in a `Create` activity, delivered via `IActivityPubClient.DeliverAsync` to the actor's outbox.

## Key changes

- `Compose.razor`: new `ContentType` property (string, "Note"/"Article"), `MaxChars` constant (500), `PostArticleAsync` method, updated `PostAsync` to branch on type, new `.compose-meta` div with count + select
- `app.css`: `.compose-meta` (flex, right-aligned), `.compose-char-count`, `.compose-char-count--over` (red), `.compose-type-select`
- `ComposeProfileIntegrationTests.cs`: updated assertion from "Post note" (button text changed to "Post") to `compose-char-count` (unique class name)

## Design decisions

- **500 char soft limit, not hard.** The counter turns red but doesn't block posting. ActivityStreams has no character limit; this is a UX suggestion for feed readability.
- **Article via `DeliverAsync`, not a new client method.** The `IActivityPubClient` has `PostNoteAsync` but no `PostArticleAsync`. Rather than adding a new client method (which would require changes to the client library + tests), the compose page constructs the `Create`/`Article` objects directly and uses the existing generic `DeliverAsync`. The server's inbox processor already handles `Article` objects (the `IdMinter` has an `Article` case, and the object store preserves types).
- **No "Question" type.** The original spec mentioned "Note, Article, Question" but ActivityStreams has no `Question` type. Note and Article cover the practical cases (short-form and long-form).
