# 40.1 — Community settings/edit

## Summary

Added the ability for a community creator to edit their community's name and description from the community detail page. The edit form is gated to the creator (detected via the Group's `AttributedTo` field, set at creation time).

## Changes

### Server: `UpdateActorAsync` generalized to `Actor`

- `IActivityPubClient.UpdateActorAsync` parameter changed from `Person` to `Actor`, enabling updates to both `Person` (profile) and `Group` (community) actors.
- `ActivityPubClient.UpdateActorAsync` implementation updated to accept `Actor`.
- All 5 test mock signatures updated to `Actor` parameter.
- `CreateCommunityAsync` now sets `Group.AttributedTo = [new Link { Href = actorId.Uri }]` so the creator is tracked.

### Server: `CommunityOutboxPublishHandler` handles `Update`

- Added `Update` case to `CommunityOutboxPublishHandler`: when a community publishes an `Update` to its own outbox with an embedded `Group` whose IRI matches the community's IRI, the mutable fields (name, summary, icon, endpoints) are merged into the stored community, preserving the `publicKey` and any `ExtensionData` the update does not carry.
- Added `HandleCommunityUpdateAsync` helper method.

### Server: `UpdateActivityHandler` community fallback

- `HandleActorUpdateAsync` now falls back to the `Communities` store when the `Actors` store doesn't contain the actor. This handles the federation path where an `Update` arrives at a community's inbox.
- Extracted `MergeActorFields` static helper to avoid duplication.

### Web: `CommunityDetail.razor` edit form

- Added `IsCreator` property: checks if the session's actor IRI is in the Group's `AttributedTo`.
- Added "Edit community" button (visible only to the creator).
- Added inline edit form (name + description) with save/cancel.
- On save: builds an updated `Group` (carrying `Id`, `PreferredUsername`, and updated `Name`/`Summary`), calls `client.UpdateActorAsync(communityIri, updatedGroup)`, invalidates the actor cache, and reloads the community.

### Tests

- `CreateCommunityAsync_SetsAttributedToToCreator`: verifies the Group's `AttributedTo` includes the creator's IRI.
- `UpdateActorAsync_OnGroup_UpdatesCommunityNameAndSummary`: verifies end-to-end community edit (create → update → name/summary changed, signing key preserved).
