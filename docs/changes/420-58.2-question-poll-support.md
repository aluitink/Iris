# 58.2 — Question / poll support (F-26)

## Summary

Added read-path support for poll data on ActivityStreams content objects. Two wire shapes are supported:

1. **Mastodon** — a top-level `poll` object in `ExtensionData` with `options` (array of `{title, votesCount}`), `endsAt`, `expired`, `multiple`, `totalVotes`.
2. **Pleroma / AS2.0** — `options` array (of `{name, votes}`) + `endTime` / `closed` / `multiple` directly in `ExtensionData`.

Inbound poll data was already round-tripping through the object store (via `[JsonExtensionData]`, proven by Phase 13.3 integration tests); this slice adds the **read path** (parsing) and **UI rendering** (a poll block with proportional option bars, vote counts, end time / ended state, and total votes).

Outbound posts do not emit poll data (Iris has no poll-creation feature yet); this slice is purely the inbound read path.

## Changes

### `PollData` / `PollOption` records + `GetPollData()` (Core)

- `PollOption(string Title, int Votes)` — namespace-level record in `Iris.Core.Identity`.
- `PollData(IReadOnlyList<PollOption> Options, int TotalVotes, DateTime? EndsAt, bool Expired, bool Multiple)` — namespace-level record.
- `IriExtensions.GetPollData(IObject?)` — reads `poll` (Mastodon) or `options`+`endTime`/`closed`/`multiple` (AS2.0) from `ExtensionData`. Returns `null` when no poll is present.
  - `ParsePollFromExtension`: Mastodon shape. `title`/`votesCount` per option; `totalVotes` falls back to sum of option votes.
  - `ParsePollFromAs2`: AS2.0/Pleroma shape. `name` (or `title`) + `votes` (or `votesCount`) per option; `endTime` (or `endsAt`); `closed` or `expired` → `Expired`.

### `ObjectView` (Web Client)

- `ObjectView.razor.cs`: added `Poll` property backed by `ResolvePoll()` (prefers `ActivityEmbeddedObject ?? Obj`, same pattern as emoji/media).
- `ObjectView.razor`: added poll block after media attachments, before the EngagementBar. Renders:
  - One row per option: a proportional background bar (width = option votes / total × 100%), option title, vote count.
  - Footer: "Poll ended" (italic) when expired; "Ends {relative time}" when not expired and `EndsAt` present; "Multiple answers allowed" when multiple; total vote count (right-aligned).

### `app.css` (Web Client)

- `.object-poll` — bordered, rounded, padded container with column flex layout.
- `.object-poll-option` — relative-positioned row, 1.75rem height.
- `.object-poll-option-bar` — absolute-positioned background bar (25% accent opacity), animated width.
- `.object-poll-option-content` — relative flex row (title left, votes right).
- `.object-poll-footer` — flex row with muted 0.75rem text; `.object-poll-total` right-aligned via `margin-left: auto`.

### Tests (Core)

- 12 new unit tests in `IriExtensionsTests` covering: null object, no poll, Mastodon poll (options/votes/endsAt/expired/multiple/totalVotes), expired+multiple, missing totalVotes (sums options), AS2.0 Question (name/votes/endTime/closed), closed→expired, no endTime (null EndsAt), option without title (skipped), empty options (null), non-object poll (null), full JSON serialization round-trip.
