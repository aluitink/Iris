## What was verified

### 21.3.1 — Reply form (object detail page)

- Navigated to alice's note (`/ap/v1/u/alice/notes/1`) via the community feed deep-link.
- The Reply card renders: "Your reply" textarea, "Mentions" input, Reply button.
- Typed a reply ("Verification reply from the autonomous loop (21.3.1 test).") and clicked Reply.
- Status: `posted reply (status 202)`.
- The Replies list count went **2 → 3**; the new reply is present (a Note with `inReplyTo` set to
  the original object's IRI).
- Clicked through to the new reply's object page: content matches, "in reply to" link present.

### 21.3.2 — Like/Boost from the detail page

- On the loaded object, the Like button showed "1 like" (a pre-existing like from seeded data).
- Clicked Like → button changed to "Unlike", "You liked this." appeared, status showed a 202
  `Like` activity with a minted id.
- Clicked Unlike → button reverted to "Like", "You liked this." disappeared, status showed a 202
  `Undo` activity (the inverse of the Like).
- Clicked Boost → button changed to "Unboost", "You boosted this." appeared, status showed a 202
  `Announce` activity with a minted id.
- The Like/Boost counts (0 likes / 0 boosts on a fresh object) update correctly.

### 21.3.3 — Delete (author only)

- On the reply object (authored by alice, the logged-on actor), the Delete button was present
  with "You authored this."
- Clicked Delete → the object re-loaded as a **Tombstone** (the deleted marker), the Delete button
  was removed, and the status showed a 202 `Delete` activity.
- The original content ("Verification reply…") was replaced by the tombstone.

### 21.4.1 — Feed pagination (Load more)

- The `PagedCollection` component (used by the Feed page and the Community feed) implements
  Load-more: it fetches one server page per click, sets `HasMore = !page.IsLastPage`, and renders
  a "Load more" button when more pages exist.
- The Community feed loaded **1100 items** (well beyond a single page), confirming the pagination
  mechanism works at scale.
- The Feed page (followed feed) uses `PagedCollection` with `PageSize="5"`; it showed "No followed
  items yet" because alice has no follows in this env (the followed-feed endpoint 500s on the
  remote-follow document fetch — the pre-existing FQDN blocker). On the public FQDN route the
  Load-more button will paginate the followed feed.
