# 59.3 — `Article`-specific fields (F-11 remainder)

## Summary

Completes F-11 (the last remaining piece). Three `Article`-specific fields that the ActivityStreams
library does not model as typed properties are now read from `ExtensionData` and surfaced in the
`ObjectView` rendering:

- **`publishedTime`**: the article's publication date (distinct from the AS2.0 `published` property,
  which is the object-creation timestamp). Read from `ExtensionData["publishedTime"]`.
- **`inLanguage`**: the article's language tag (e.g. `"en"`, `"fr-CA"`). Read from
  `ExtensionData["inLanguage"]`.
- **`duration`**: the article's reading duration (e.g. `PT1H30M` = 1h 30m). Already a typed
  property on the `Object` base class (`TimeSpan? Duration`), so read directly from the object.

These are rendered in the `ObjectView`'s generic `IObject` branch (the branch that handles
`Note`/`Article`/other content objects) as a compact metadata line: publication date, duration, and
language tag.

## Changes

### `IriExtensions.GetPublishedTime` (Iris.Core)

New extension method `GetPublishedTime(this IObject?)` reads the `publishedTime` string from
`ExtensionData` and parses it as a UTC `DateTime`. Returns `null` when the object is null, has no
`ExtensionData`, the key is absent, the value is not a string, or the string is not parseable as a
date.

### `IriExtensions.GetInLanguage` (Iris.Core)

New extension method `GetInLanguage(this IObject?)` reads the `inLanguage` string from
`ExtensionData`. Returns `null` when the object is null, has no `ExtensionData`, the key is absent,
the value is not a string, or the string is whitespace.

### `ObjectView.razor.cs` (Iris.Web.Client)

Three new private properties:

- `ArticlePublishedTime`: reads `GetPublishedTime()` from the embedded object (for activity-wrapped
  items) or the direct object, falling back to `Obj`.
- `ArticleInLanguage`: reads `GetInLanguage()` from the embedded object or the direct object.
- `ArticleDuration`: reads the typed `Duration` property from the embedded object or the direct
  object (only when it's an `ActivityObject` with a non-null `Duration`).

### `ObjectView.razor` (Iris.Web.Client)

In the generic `IObject` branch, after the `Updated` block and before the `ParentIri` block, three
optional metadata lines are rendered:

- `publishedTime`: a `<time>` element with the local-time display and the UTC ISO-8601 in `title`.
- `duration`: a formatted duration string (e.g. `"1h 30m"` or `"45 min"`).
- `inLanguage`: the language tag as plain text.

Each is wrapped in `<div class="object-article-meta">` and only rendered when the value is present.

## Design notes

- `duration` is already a typed `TimeSpan?` on the `Object` base class (the library deserializes the
  AS2.0 `duration` property via `XMLTimeSpanConverter`), so no extension method is needed — it's read
  directly.
- `publishedTime` and `inLanguage` are not in the ActivityStreams 2.0 vocabulary the library models;
  they land in `ExtensionData`. The extension-method pattern (same as `GetCustomEmojis`,
  `GetPollData`, `GetRichAttachments`) keeps the `ExtensionData` parsing in `Iris.Core` where the
  library-agnostic boundary lives.
- The three properties are computed from `ActivityEmbeddedObject ?? Obj` (same pattern as
  `ResolveEmojiTags` and `ResolvePoll`), so they work both for direct-object rendering and for
  activity-wrapped items (a `Create` whose embedded object is an `Article`).
