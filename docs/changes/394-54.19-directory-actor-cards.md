# 54.19 — Directory actor cards, split into Communities/People tabs

Phase 54 slice. The actor directory listed all local actors (people and communities) in a single flat
list, each rendered as a minimal card with only a name, handle, and a follow button — no avatar, no
bio/summary, and no way to preview an actor's recent posts without navigating to their detail page.
The slice asked for: (1) a card per actor using their icon/image, display name/handle, and a short
bio/summary, with a "+" expand affordance to reveal that actor's most recent posts inline; and
(2) a split into two tabs — **Communities** and **People** — so Group-like actors and individual
actors are browsed separately.

## Change

1. **Split the directory into People / Communities tabs**
   ([Directory.razor](../../apps/Iris.Web.Client/Components/Pages/Directory.razor)):
   - Added a `.tab-bar` with two tabs ("People" and "Communities"), defaulting to "People".
   - `LoadActorsAsync` now collects all actors (via `SearchAsync` with `Type = "Actor"`), filters
     them into two lists: `People` (actors that are **not** `Group`) and `Communities`
     (`Group` actors), each sorted alphabetically by `preferredUsername`.
   - The tab switch is client-side only (`ActiveTab` state); the actor list is loaded once on init
     and both tabs read from the same in-memory lists.

2. **New `DirectoryCard` component — actor card with avatar, name, handle, bio, and expandable posts**
   ([DirectoryCard.razor](../../apps/Iris.Web.Client/Components/DirectoryCard.razor)):
   - **Avatar**: a circular `.directory-card-avatar` (2.5rem) showing the actor's `icon` (first
     icon IRI, same-origin-rewritten via `RewriteMediaToSameOrigin`, mirroring `ObjectView`'s
     pattern) as an `<img>`, or an initial-letter fallback (`.directory-card-avatar-fallback`) when
     the actor has no icon.
   - **Name + handle**: the actor's `name` (or `preferredUsername` as fallback) in a
     `.directory-card-name` link to `/actor?iri=…`, and the handle (last path segment of the
     actor IRI) in `.directory-card-handle`.
   - **Bio/summary**: the actor's `summary` (first entry), truncated to 150 chars, in
     `.directory-card-summary`.
   - **Expand affordance**: a circular "+" button (`.directory-card-expand`, "Show posts"
     aria-label) that, when clicked, calls the parent's `OnExpandPosts` callback. When expanded,
     the "+" becomes "−" ("Hide posts").
   - **Recent posts**: when expanded, a `.directory-card-posts` section renders up to 3 content
     items (Create of Note/Article, per `OutboxFilter.IsContentItem`) from the actor's outbox,
     each in a `.directory-card-post` card using the existing `ObjectView` component (which renders
     the full post: actor avatar, handle, timestamp, content, media, and engagement bar).
   - **Follow button**: the existing `FollowButton` component is rendered alongside the expand
     button (top-right of the card header).
   - Clicking the card header (not the follow button) toggles the expand state.

3. **Expand logic in `Directory.razor`**:
   - `ExpandAsync(Actor)` fetches the actor's outbox via
     `client.GetCollectionAsync(new Iri(actorId).OutboxOf())`, walks the pages collecting content
     items (via `OutboxFilter.IsContentItem`) until 3 are found or the collection is exhausted.
   - Results are cached in a `Dictionary<string, List<IObjectOrLink>>` keyed by actor IRI; a
     `HashSet<string>` tracks in-flight loads (prevents duplicate fetches).
   - A failed fetch stores an empty list (the card shows "No recent posts." in the expanded state).

4. **CSS** ([app.css](../../apps/Iris.Web.Client/wwwroot/css/app.css)):
   - `.directory-cards`: vertical flex column with 0.75rem gap.
   - `.directory-card`: bordered card with 8px radius, `overflow: hidden`.
   - `.directory-card-header`: flex row (avatar + info + expand + follow), cursor pointer.
   - `.directory-card-avatar` / `.directory-card-avatar img` / `.directory-card-avatar-fallback`:
     2.5rem circular avatar.
   - `.directory-card-info` / `.directory-card-name` / `.directory-card-handle` /
     `.directory-card-summary`: name (bold, accent on hover), handle (muted), bio (muted,
     truncated).
   - `.directory-card-expand`: 1.75rem circular "+" button (muted, surface background).
   - `.directory-card-posts` / `.directory-card-post`: expanded posts section with border-top
     separator; each post in a nested bordered card.
