New core unit tests (2) + `InboundUppercaseDigestIntegrationTests` (3) lock both casings round-tripping and the tamper rejection. [changes/230-22.12-mastodon-digest-header-casing.md](changes/230-22.12-mastodon-digest-header-casing.md)

[changes/231-22.13-cross-instance-moderation-undo-propagation.md](changes/231-22.13-cross-instance-moderation-undo-propagation.md)
